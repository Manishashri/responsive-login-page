# Responsive Login and Signup Authentication UI

## Project Overview

This project is a responsive Login and Signup Authentication UI developed using HTML, CSS, and JavaScript.

The application allows users to:

- Register using Signup page
- Login using registered credentials
- Validate email and password
- Store user data using Local Storage
- Display personalized welcome message after login

The project is fully responsive and works on desktop and mobile devices.

---

## Features

### Login UI
- Modern responsive login page
- Email and password authentication
- Error handling for invalid credentials

### Signup UI
- User registration form
- Confirm password validation
- Strong password validation

### Form Validation
- Empty field validation
- Regex email validation
- Strong password validation:
  - Minimum 8 characters
  - Uppercase letter
  - Lowercase letter
  - Number
  - Special character

### Welcome Page
- Displays:
  
```bash
Welcome Back Username
```

- Logout functionality included

---

- HTML5

---

## How the Project Works

### Step 1: User Registration
The user creates an account using the Signup page.

### Step 2: Validation
The application validates:
- Email format
- Password strength
- Confirm password matching

### Step 3: Store Data
User credentials are stored using browser Local Storage.

### Step 4: Login Authentication
During login, entered credentials are verified with stored data.

### Step 5: Welcome Page
After successful login, the user is redirected to a personalized welcome page.
